# Phase 6b frozen plan

This commit freezes the plan and evaluation set only. No Phase 6b tracer, trace pass, or benchmark execution is part of this step.

a. **Hypothesis.** File-level coverage selection keeps every reference regression while executing at least 50% fewer tests on the patched tree. Function-level is reported as secondary.

b. **Evaluation set.** Fixed: the seven Phase 5 regression tasks (django-10973, django-12209, django-14140, django-14631, matplotlib-25479, pytest-5809, sphinx-10435; 12 reference IDs). Deviation from the roadmap, recorded: the "4 incorrect-patch tasks with grader failures" are dropped, because after the label audit the seven grader-failing tests resolve to one genuine case (matplotlib-25479, already in the set), one stale-candidate artifact (django-13297) and five CPU-skip artifacts (pylint-6528, pylint-7277). Known tests are now the 12 reference IDs. This deviation records the supplied audit conclusion; no correctness labels are opened in 6b.

Seeded: 6 more tasks. Pool = runner pytest, not sympy, ordering_eligible in `phase5_replay/per_task_costs.csv`, patched_execution_s <= 180, not in the fixed set. With `random.Random(20261114)`: sample 6 repositories from the sorted pool repositories (all of them if fewer than 6), then for each chosen repository in sorted order choose one task from the sorted task ids. The same generator is used for the repository sample and subsequent task choices. Seeded tasks have no reference regression, so recall is vacuous there; they count for reduction, overhead and outcome agreement.

c. **Scope.** pytest and Django runtests runners only.

d. **Tracing.** `sitecustomize` mounted read-only via `PYTHONPATH`, no coverage.py, no image changes. Function-call events only (global trace function, no local trace), `threading.settrace` for threads. Per test record the set of `(co_filename, co_name, co_firstlineno)`. Attribution covers everything between test start and end including setup, teardown and fixtures; class-, module- and session-level setup is attributed to every test in scope. A test whose execution the tracer cannot fully see (multiprocessing workers, C threads) is flagged `TRACE_INCOMPLETE` and always retained; a test with no trace (skipped, errored, not reached) is retained and counted. Absence is never evidence.

e. **Per-task procedure.** In the Phase 4 images with `--network none` and `--cpu-shares 2048`: (1) untraced base pass of the Phase 4 V2 list; (2) traced base pass, same list; (3) build file-level and function-level selections from the traced base map and the frozen patch's changed files and AST-qualified functions (as in 6a); (4) patched pass of each selection; (5) compare with the sealed Phase 4 patched outcomes for the same IDs. The full patched V2 list is not rerun; its cost baseline is the sealed Phase 4 module durations.

f. **Metrics, per task and pooled.** Recall of the 12 reference IDs (file and function level); selected / V2 list size; reduction `r = 1 - selected_executed / V2 size`; tracing overhead `T = traced base time / untraced base time` (execution-only, module-process sum); total cost = traced base + selected patched pass vs baseline = untraced base + sealed full patched pass; reusable-history cost = selected patched pass vs full patched pass; traced/untraced outcome disagreements per test; blind-spot counts (`TRACE_INCOMPLETE`, patch-only functions or files absent from base, tests without a trace).

g. **Pre-registered reading.** Success: file-level keeps 12/12 reference IDs AND the median per-task reduction is at least 50% AND zero traced/untraced disagreements on tests that were stable in Phase 4 (tests with a Phase 4 FLAKY record are excluded from this criterion and listed). Failure: any reference regression missed at file level, or any disagreement on a stable test. Adopt for later work only if success AND total cost is below baseline on both the pooled and the median-task basis. Break-even, stated now: coverage beats baseline only if `(T - 1) * B < r * P`, where `B` is untraced base execution time and `P` is sealed full patched execution time.

h. **Infrastructure halt.** A halt for infrastructure failure (not a test result) records no numbers. Fix it, amend the plan, restart the whole 6b run from task 1.

i. **No label access.** No correctness labels are opened anywhere in 6b. No oracle data or model calls are permitted.

The evaluation set is generated by `scripts/phase6b_select_set.py` from pinned Phase 5 costs/reference IDs and the frozen paired-harness task metadata. `reports/next_phases/phase6b_plan/eval_set.json` records the tasks and repository pool sizes. Its whole-file SHA-256 is recorded in the sibling `eval_set.sha256`, avoiding a self-referential JSON hash. Two independent invocations must be byte-identical before the plan tag is created. Existing tags and sealed results are unchanged.
