# Fix 10: pre_install proof implementation

The project dependency remains swebench 5.0.2. Its installed package has no pre_install specs. The separate 4.0.4 wheel is retained under ignored `runs/phase4_fix10_provenance/`, never installed or imported. [Provenance](fix10_provenance/provenance.json) records the PyPI download URL, wheel SHA-256, and four-column dataset projection hash. The parser reads only the Python constituent `MAP_REPO_VERSION_TO_SPECS_PY` of the combined map, retaining only pre_install fields. A missing repo/version or unsupported AST construct halts.

The [dataset projection](fix10_provenance/dataset_projection.json) was generated from the existing local Verified Arrow snapshot with IPC included_fields set to instance_id, repo, base_commit, version. No other column values were decoded. The original snapshot was hashed opaquely. All 83 frozen task identities match. The generation script reproduces this projection without loading datasets rows.

For literal source-edit command lists, all target base blobs are copied into an isolated temporary directory, and every command is applied in order there. Neither the image nor the archive is rewritten. Every target archive entry must equal its base blob and every image target must equal the replay result, even when a missing command effect would leave no raw image/archive mismatch. Other source mismatches still halt. System/package/network commands are never executed on the host and cannot justify a source exemption. The independent export-subst proof is unchanged.

On each image needing a source-edit proof, the guard reads the documented setup script locations. The complete sed-command subsequence must equal the ordered source-edit spec exactly; any extra, missing or reordered command halts. A present script that cannot establish that equality is rejected. No script is recorded explicitly as "no image script" with the checked paths. Receipts retain package/spec/command identity, hashes, expected bytes, and script evidence.
